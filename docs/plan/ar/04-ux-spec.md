# 04 — مواصفات تجربة الاستخدام

التصاميم البصرية لكل شاشة تعيش في مخطط سلامتك التفصيلي (blueprint artifact)؛ أما هذه الوثيقة فهي العقد المكتوب: الغرض والمحتويات والحالات والحالات الحدّية لكل شاشة، إضافة إلى الأنظمة المشتركة العابرة للشاشات (الروابط المباشرة والإشعارات).

## هيكلة المعلومات

```
تطبيق العميل (عربي RTL، PWA → تطبيق أصلي لاحقًا)
├── الرئيسية (SOS)                          C2
│   ├── مساعد الحادث                        C3
│   └── معالج طلب السطحة                    C4  (الموقع → السيارة → الصور → الوجهة)
├── القضية النشطة
│   ├── التتبع المباشر                      C5
│   ├── خط زمن القضية                       C6
│   ├── العرض والمقارنات                    C7
│   ├── الاعتماد والدفع                     C8
│   ├── مساعد التأمين                       C9
│   ├── تقدم الإصلاح                        C10
│   └── التسليم والتقييم                    C11
├── سياراتي / القضايا السابقة / بطاقات الضمان
└── الإعدادات (اللغة، الإشعارات) · التسجيل الأولي C1

لوحة الإدارة (عربي RTL، ويب متجاوب)
├── لوحة المؤشرات                 O1
├── التوزيع                       O2
├── القضايا (قائمة → تفاصيل)      O3 → O4
├── العروض (المنشئ)               O5
├── لوحة الورشة                   O6
├── دليل الأسعار                  O7
├── المخزون وأوامر الشراء         O8
├── مسار مطالبات التأمين          O9
├── المالية                      O10
└── الفريق والإعدادات

وضع السائق (نفس تطبيق PWA، بدور السائق)
D1 قائمة المهام → D2 المهمة والملاحة → D3 توثيق الاستلام → D4 التحصيل والإغلاق
```

## شاشات العميل

| # | الشاشة | الغرض | يجب أن تحتوي | الحالات الرئيسية والحالات الحدّية |
|---|---|---|---|---|
| C1 | التسجيل الأولي | تسجيل الدخول برقم الجوال ورمز OTP مع مخرج للطوارئ | حقل رقم الجوال، خانات رمز OTP، مخرج «اطلب سطحة بدون تسجيل» | مهلة تهدئة لإعادة إرسال OTP؛ واتساب بديلًا احتياطيًا عند عدم وصول SMS؛ مسار الضيف يربط الحساب لاحقًا |
| C2 | الرئيسية (SOS) | امتلاك لحظة الهلع | زر «عندي حادث» الضخم؛ إجراءات سريعة (سطحة بدون حادث، تتبّع، عروضي)؛ شريط وعد السطحة المجانية؛ بطاقة القضية النشطة | تُعرض داكنة في كل السمات (عن قصد)؛ عند عدم تسجيل الدخول يبقى الزر يعمل؛ القضية النشطة تُحِلّ بطاقة التقدم محل الواجهة |
| C3 | مساعد الحادث | خطوات السلامة والخطوات النظامية بالترتيب | خطوة الاتصال بـ 997 (تتصدر عند وجود إصابات)، خطوة السلامة، الاتصال بنجم 920 000 560، صور موقع الحادث | جميع الخطوات قابلة للتخطي؛ الصور تُزامَن في الخلفية؛ حالة قائمة التحقق → القضية |
| C4 | معالج طلب السطحة | الطلب بلا أي مفاجآت | شريط خطوات (الموقع→السيارة→الصور→الوجهة)؛ دبوس الخريطة؛ حقل السيارة؛ بطاقات الوجهات بين 0 ر.س والرسوم؛ زر التأكيد يكرر ذكر الرسوم | لا GPS → سحب الدبوس / مشاركة الموقع عبر واتساب؛ خارج المدينة بتسعير لكل كيلومتر؛ إشارة الرسوم الليلية الإضافية تظهر قبل الطلب |
| C5 | التتبع المباشر | الطمأنة أثناء الانتظار | الخريطة + المسار + شارة وقت الوصول المتوقع؛ بطاقة السائق (الاسم/الصورة/اللوحة/التقييم)؛ اتصال؛ مشاركة مع العائلة؛ سلّم الحالات | انزلاق وقت الوصول > 10 دقائق → إشعار استباقي؛ رابط المشاركة عام ومحدود الصلاحية؛ الإلغاء مجاني حتى تحميل السيارة |
| C6 | خط زمن القضية | إنهاء مكالمات «ما الذي يحدث؟» | سجل الأحداث (السطحة، الوصول، الفحص، الموعد المتوقع للعرض)؛ صف المستندات (نجم، الصور)؛ زر الدعم عبر واتساب | تجاوز SLA الخاص بالعرض → اعتذار + موعد جديد؛ دعم إرفاق تقرير نجم متأخرًا |
| C7 | العرض | التحويل عبر الشفافية | مبدّلات المصدر لكل بند أصلي/تجاري/مستعمل مع الأسعار + الضمان؛ بنود أجور عمل ثابتة؛ مرجع سعر الوكالة + التوفير؛ إجمالي شامل ضريبة القيمة المضافة؛ مدة الصلاحية؛ أزرار الاعتماد + PDF/طرح سؤال | المصدر غير المتوفر يُعطَّل مع موعد توفره؛ انتهاء الصلاحية → إعادة تأكيد الأسعار؛ النسخة v2 تعرض شارة الفروقات |
| C8 | الاعتماد والدفع | الالتزام بأمان | ملخص (الإجمالي، العربون، المدة، الضمان)؛ مبدّل مقسّم لطرق الدفع (مدى/Apple Pay/تحويل/نقدًا)؛ تنويه OTP | فشل الدفع → إعادة المحاولة/تبديل الطريقة، والقضية `APPROVED_UNPAID`؛ الشروط قابلة للتهيئة |
| C9 | مساعد التأمين | جعل التأمين سببًا لاختيارنا | بطاقة الوثيقة/شركة التأمين؛ رقم نجم + الحالة؛ الخيار أ (مستشار التعويض مع الأرقام الثلاثة) مقابل الخيار ب (إصلاح مباشر عبر شركة التأمين مع شارات مسار المطالبة) | المستشار لا يظهر إلا بتقدير تعويض يُدخله الموظفون؛ نص ضد الغير يختلف عن نص الشامل؛ الخسارة الكلية تُوجَّه إلى شاشة النصح |
| C10 | تقدم الإصلاح | الإثبات فوق الوعود | نسبة الجاهزية % + اليوم المتوقع؛ خط زمني للمراحل مع صور لكل مرحلة؛ أسباب تأخير صادقة | التأخير → يتحرك الموعد المتوقع مع ذكر السبب؛ إخفاق فحص الجودة يظهر بوصفه «إعادة فحص» ولا يُخفى |
| C11 | التسليم والتقييم | إغلاق دافئ يزرع القضية التالية | بطاقتا موعد الاستلام مقابل التوصيل المدفوع؛ فاتورة برمز QR وفق ZATCA + المبلغ المتبقي؛ التقييم؛ بطاقة رصيد الإحالة؛ بطاقة الضمان | عدم الاستلام > N من الأيام → تحذير سياسة التخزين؛ التقييم علني وفق السياسة |

## الروابط المباشرة (تكافؤ بدون تثبيت)

لكل نقطة تواصل مع العميل صفحة ويب برمز وصول (token) — تُسلَّم هذه الروابط عبر واتساب/SMS بحيث تعمل الرحلة كاملة دون التطبيق:

| الرابط | المحتوى | المصادقة |
|---|---|---|
| التتبع | مكافئ C5 (خريطة مباشرة، بطاقة السائق) | الرمز في عنوان URL، وتنتهي صلاحيته عند التسليم |
| مشاركة الرحلة | نسخة C5 للقراءة فقط للعائلة | رمز عام، تنتهي صلاحيته عند التسليم |
| العرض | C7 مع المبدّلات + الاعتماد (رمز OTP لخطوة E1 يتم داخل الصفحة) | رمز + OTP عند الاعتماد |
| الدفع | صفحة مستضافة لدى مزود الدفع PSP للعربون/المتبقي/رسوم السطحة | جلسة PSP |
| التقدم | مكافئ C10 | رمز |
| الفاتورة | PDF + رمز QR وفق ZATCA | رمز |

القواعد: الرموز مقيدة بقضية واحدة، وقابلة للإبطال، وتنتهي صلاحيتها عند إغلاق القضية (رابط الفاتورة يبقى)؛ الصفحات للقراءة فقط باستثناء الاعتماد/الدفع؛ وكل صفحة تحمل الخط الساخن ورابط واتساب المباشر.
