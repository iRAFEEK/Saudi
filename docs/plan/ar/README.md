# سلامتك Salamtak — خطة المنتج

**أول اتصال بعد الحادث — The first call after the accident**

منصة تمتد من الحادث إلى الإصلاح في الرياض. حين يقع الحادث، «سلامتك» هو الزر الذي يضغطه صاحب السيارة: سطحة تصل خلال دقائق، والسيارة تتجه إلى ورشتنا، ويستلم عرض سعر شفافًا مفصّلًا بالبنود مع مقارنات أسعار حقيقية — **والسحب مجاني إذا أصلح عندنا**. وخلف ذلك كله، لوحة إدارة متكاملة تُشغّل العملية بأكملها: القضايا، والتوزيع، والتسعير، والورشة، والتأمين، والمال.

> **المخطط التصميمي:** كل شاشة في المنتج (11 للعميل، و10 للتشغيل، و4 للسائق) مصمّمة في مخطط HTML المرافق المنشور بوصفه Claude artifact ‏("Salamtak سلامتك"). وتحمل هذه الوثائق العمق المكتوب الذي يقف خلف تلك التصاميم.

## نموذج العمل في فقرة واحدة

السحب ليس منتجًا — إنه **اكتساب للعملاء**. نصل أولًا (المستهدف ≤ 30 دقيقة)، ونسحب مجانًا، ونكسب الإصلاح بعرض سعر يقارنه العميل بندًا بندًا (أصلي / تجاري / مستعمل مقابل سعر الوكالة). فإن رفض، دفع رسوم السحب فقط (مثلًا 150 ر.س، معلنة مسبقًا) وغادر ومعه عرض سعر PDF يحمله أينما شاء — قضية لا تزال مربحة قليلًا، وصاحبها لا يزال عميلًا مستقبليًا. والرقم الوحيد الذي يعمل النظام كله على تحسينه هو **معدل التحويل من سحب إلى إصلاح** (المستهدف ≥ 55%).

## قرارات النطاق (اتُّفق عليها في 2026-08-16)

- **المنتج الأولي MVP يُطلق الجانبين معًا**: تطبيق العميل ولوحة الإدارة — إطلاق واحد متكامل، بمنهج التصميم أولًا.
- **التأمين وحدة كاملة في الإصدار v1** (تصنيف النوع عند الاستقبال، والتقاط تقرير نجم، ومسار المطالبات، ومستشار التعويض، والمستحقات) — لا واجهة مبتورة تكتفي بالتقاط البيانات.
- **الوثائق بالإنجليزية؛ والمنتج عربي أولًا** (كل نصوص الواجهة في التصاميم عربية حقيقية).
- **العلامة التجارية المؤقتة: سلامتك Salamtak** — التحقق من العلامة/الاسم لا يزال معلّقًا؛ فتُعامل في الكود اسمًا مؤقتًا (`salamtak`).

## المسرد

| المصطلح | المعنى |
|---|---|
| سطحة (satha) | شاحنة السحب ذات السطح المستوي — المركبة نفسها، وبالعامية اسم الخدمة أيضًا |
| نجم (Najm) | شركة نجم لخدمات التأمين — تحضر الحوادث وتُصدر التقرير الذي تشترطه شركات التأمين (920 000 560) |
| تقدير (Taqdeer) | تقييم أضرار المركبة الذي تعتمده شركات التأمين لتثمين المطالبات |
| الوكالة (al-wakala) | مركز خدمة الوكالة — المرجع الأعلى للسعر |
| تشليح (tashleeh) | سوق التشليح وقطع الغيار المستعملة (مثل القطع المستعملة الواردة من ساحات الخردة) |
| شامل (shamel) | التأمين الشامل — تدفع شركة تأمين العميل نفسه |
| ضد الغير (dhid al-ghair) | تأمين المسؤولية تجاه الغير — تدفع شركة تأمين الطرف المتسبب |
| أصلي / تجاري / مستعمل | OEM / aftermarket / used — خيارات مصدر القطعة الثلاثة في كل عرض سعر |
| ZATCA / فاتورة | منظومة الفوترة الإلكترونية لهيئة الزكاة والضريبة والجمارك السعودية (فواتير برمز QR، وضريبة قيمة مضافة 15%) |
| مدى (mada) | شبكة بطاقات الخصم السعودية المهيمنة |
