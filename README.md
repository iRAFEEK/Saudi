# سلامتك Salamtak

**The first call after the accident — أول اتصال بعد الحادث**

An accident-to-repair platform for Riyadh: one-tap tow (سطحة) with live tracking, transparent itemized repair estimates with real price comparisons (أصلي / تجاري / مستعمل vs the dealership), full insurance-claim handling — and a complete management console for the operation behind it. Towing is free when the customer repairs with us.

📋 **Start here:** [`docs/plan/`](docs/plan/README.md) — the full product plan: vision & unit economics, personas & journeys, 70 user stories with acceptance criteria, screen-by-screen UX spec, design system, data model & architecture, and the roadmap.

🎨 The complete visual design (all 25 screens: customer app, ops console, driver mode) lives in the companion "Salamtak سلامتك" blueprint artifact.

**Status:** Phase 0 — design & validation. No application code yet; Phase 1 (MVP, both sides) scope is defined in [the roadmap](docs/plan/07-roadmap-and-metrics.md).
